Privacy Policy

Last updated: November 6, 2026

Following Studio is an independent application for organizing and reviewing X accounts. It is not affiliated with X Corp.

1. Information we process

When authorized, Following Studio may retrieve account identifiers, public profile information, follower and following lists, and available posts through the official X API. Users may also import account lists, add notes, assign folders, and record review decisions.

2. How information is used

Information is used to display account lists, organize folders, generate available content summaries, and help users make their own account-management decisions. Following Studio does not automatically unfollow accounts without explicit authorization.

3. Storage and authentication

The current browser extension stores imported account data, folders, notes, and review decisions locally in the user's browser. OAuth authentication uses X's authorization process rather than collecting X passwords. Authorization tokens may be stored temporarily in browser extension session storage.

4. Data sharing

The current local application does not sell personal information or operate an analytics database. Authorized API requests exchange necessary information with X. Future cloud or AI integrations will require updated disclosures and appropriate user consent before activation.

5. Your choices

Users can export or delete locally stored data, disconnect an authorized X account, and revoke app authorization through X's account settings. Removing the extension may also remove locally stored information.

6. Security and limitations

Following Studio is under development. No software can guarantee complete security. Users should avoid importing sensitive information they do not want stored on their device.

7. Changes to this policy

This policy may be updated as features, hosting, authentication, and data processing change. Material changes will be disclosed before affected features are enabled.

8. Contact

For privacy inquiries, contact the project maintainer through the GitHub issue tracker.
